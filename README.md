# Smart GPS-Free Bus Tracking System using RFID & NFC

## Internship Project

This repository contains the technical work for a Smart GPS-Free Bus Tracking System using RFID and NFC.

### Project Progress

- **Week 1:** Project Planning and Requirements Analysis
- **Week 2:** Circuit Design and Simulation
- **Week 3:** Prototype Assembly and Hardware Integration

### Week 3 Deliverables

The Week 3 report documents:
- Prototype hardware architecture
- Detailed bill of materials and cost breakdown
- ESP32, RC522 RFID and PN532 NFC interface plan
- Corrected wiring and GPIO allocation
- Power supply integration
- Assembly procedure
- Process-flow and operating sequence
- Numerical validation targets and testing methodology
- Test points, test cases and risk mitigation
- Iterative testing schedule and design optimization

> Note: Estimated/design values are clearly distinguished from physical measurements. Actual LTspice screenshots and prototype photographs should be added when the corresponding tests are completed.
